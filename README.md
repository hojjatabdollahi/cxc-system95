# System95 theme bundle for COSMIC DE

The Windows 95 look as a COSMIC theme bundle, the classic gray colors, the Chicago95 icon set, the W95FA recreation of the Windows 95 UI font, and a CC0 wallpaper  in place of the original Clouds wallpaper.
Download `system95.zip` from the latest release and import it under Settings > Desktop > Appearance.
